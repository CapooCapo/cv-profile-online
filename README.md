# Do Gia Hoang online CV profile

Static, responsive one-page profile built from the current CV.

## Preview locally

```sh
cd cv-profile
python3 -m http.server 8080
```

Then open <http://localhost:8080>.

## Publish

This directory can be deployed as-is to GitHub Pages, Netlify, Cloudflare Pages, or Vercel. No build step or dependency is required.
